# macOS 网页版 (Web macOS)

一个完全在浏览器中运行的 macOS 桌面模拟体验，纯静态实现。

## 在线体验

**[https://user-henry.github.io/webmacos/](https://user-henry.github.io/webmacos/)**

## 功能特性

### 核心系统
- 完整的窗口管理器（拖拽、缩放、最小化、全屏）
- macOS 风格菜单栏与程序坞 (Dock)
- 桌面图标管理与文件操作
- 聚焦搜索 (Spotlight)
- 控制中心（Wi-Fi、蓝牙、亮度、音量等）
- 通知中心与横幅通知
- 锁屏与屏保

### 多用户登录
- **Henry** 账号：密码登录保护
- **客人用户**：无需密码，即点即用
- 支持切换用户，各自独立的文件系统

### 内置应用
- 访达（文件管理、多视图、拖拽排序）
- 终端（完整 Shell 模拟）
- Safari 浏览器（内置页面、收藏夹、搜索引擎）
- 文本编辑（新建/保存/另存为）
- 备忘录（自动保存、搜索）
- 计算器（完整键盘支持）
- 日历（事件管理、提醒）
- 照片（图库浏览、灯箱）
- 音乐（6首 CC-BY 曲目）
- QuickTime 播放器（3个内置视频）
- 预览（图片/PDF/文本）
- 地图（离线设计地图）
- 天气（小组件）
- 系统设置（完整设置面板）
- App Store（可扩展的应用生态）
- 启动台、时钟、活动监视器

## 技术栈

- 纯 HTML/CSS/JavaScript（零依赖、零构建）
- localStorage 持久化数据存储
- 虚拟文件系统（Tree-structured JSON）
- 事件总线驱动架构
- 完全响应式设计

## 本地运行

直接在浏览器中打开 index.html 即可，无需任何构建工具或服务器。
